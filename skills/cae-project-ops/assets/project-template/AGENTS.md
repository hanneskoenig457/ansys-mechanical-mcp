# Agent instructions

- Read `README.md` and the linked project state before acting.
- Inspect existing files and preserve unrelated work.
- Start with read-only inspection and distinguish planned, observed, inferred,
  and validated claims.
- Do not solve, save, overwrite, delete, or publish engineering artifacts
  unless the task places that action in scope.
- When behavior, structure, assumptions, decisions, validation, or completed
  subtask status changes, update the affected documentation in the same task.
- Before completion, classify new files, flag task-generated clutter, record
  checks and remaining uncertainty, and provide a concise handoff.
